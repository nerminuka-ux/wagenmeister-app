WAGENMEISTER PRIVAT – iPHONE WEB-APP V2

Diese Version ist als installierbare PWA für Safari/iPhone vorbereitet.

Enthalten:
- iPhone-optimierte Oberfläche
- Home-Bildschirm-Icon
- lokale Kesselwagen-Datenbank
- Wagennummer suchen und Wagen automatisch übernehmen
- eigene Kesselwagen dauerhaft speichern
- Fotoaufnahme der Wagennummer
- OCR-Versuch über Tesseract.js (Internetverbindung beim ersten Laden erforderlich)
- Wagenliste und automatische Summen
- PDF/Drucken über Safari
- Zugvorbereitung/Bremsprobe
- Datenbank Export/Import als JSON
- Offline-Grundfunktionen nach erstem Laden

WICHTIG:
Die App muss über HTTPS auf einem Webserver liegen, damit iPhone/PWA, Kamera und Offline-Funktionen zuverlässig arbeiten.
Einfachste kostenlose Möglichkeiten: GitHub Pages, Netlify oder Cloudflare Pages.

Installation auf iPhone:
1. veröffentlichte HTTPS-Adresse in Safari öffnen
2. Teilen
3. Zum Home-Bildschirm
4. Hinzufügen

Die App ist ein privater Prototyp und nicht als sicherheitsrelevante betriebliche Freigabe- oder Berechnungssoftware zertifiziert.
